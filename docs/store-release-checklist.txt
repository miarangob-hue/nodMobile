NOD Store Release Checklist
===========================

Builds
------
Android preview APK:
npm run build:preview

Android production AAB:
npm run build:android

iOS production IPA:
npm run build:ios

Subir a stores:
npm run submit:android
npm run submit:ios

Requisitos antes de subir
-------------------------
1. Ejecutar npm run typecheck.
2. Ejecutar npx expo export --platform android --output-dir dist/android.
3. Configurar cuenta EAS con eas login.
4. Si el proyecto no existe en EAS, ejecutar npx eas init.
5. Confirmar que com.nod.mobile esta disponible en Google Play Console y App Store Connect.
6. En Google Play, crear app y completar Data Safety.
7. En App Store Connect, crear app y completar Privacy Nutrition Labels.
8. Publicar una Privacy Policy URL.
9. Preparar screenshots de Android e iPhone.
10. Revisar que las API keys productivas esten en variables de entorno del build, no hardcodeadas.

Permisos declarados
-------------------
Camera:
Documentos de onboarding, evidencia de servicios y spots desbloqueados.

Location:
Inicio de paseos, ruta del servicio y spots desbloqueados.

Secure Store:
Sesion local del usuario.

Datos sensibles a declarar
--------------------------
Nombre, email, telefono, RUT, direccion, ubicacion aproximada/precisa, fotos, datos de mascotas, datos medicos de mascotas, historial de reservas y pagos.

Pendientes de backend antes de produccion completa
--------------------------------------------------
1. Login cliente real con POST /login y role customer.
2. GET /providers para mostrar paseadores reales.
3. Escritura cliente para mascotas, reservas, soporte, spots, ficha medica y seguros.
4. Sincronizacion de spot unlocked.
5. Sincronizacion de ficha medica.
6. GET /insurance-plans y POST /insurance-requests.
